# Futuristic Shooter

Een Doom-achtige shooter met een futuristische neon esthetiek.

## Features

- **Raycasting Engine**: Klassieke Doom-stijl 3D rendering
- **Futuristische Look**: Neon kleuren en gloed effecten
- **Player Movement**: WASD controls met muis look
- **Shooting Mechanic**: Basis schiet systeem met ammo
- **HUD**: Health bar en ammo counter

## Controls

- **WASD**: Beweging
- **Muisknop**: Schieten
- **ESC**: Menu/Pause

## Toekomstige Features

- Enemy AI en spawn systeem
- Meerdere wapens
- Power-ups
- Level systeem
- Sound effects
- Particle effects

## Setup

Open gewoon `index.html` in je browser. Geen build proces nodig!
